# STYLD engineering checklist

Use this checklist for every UI or discovery change.

## Beauty World coverage

Evaluate every UI feature across:

- Pure
- Feminine
- Natural
- Spiritual
- Cultural
- African Nude

Check Calm, Balanced and Immersive where atmosphere applies.

A reusable component must not require a separate implementation for every world.

## Required checks

- World-sensitive design tokens are used.
- Pure baseline is preserved.
- Typography and logo integrity are unchanged.
- Contrast and focus visibility are verified.
- Responsive layout is verified at agreed viewports.
- Reduced motion is verified.
- Navigation continuity is preserved.
- Client-workspace isolation is preserved.
- Supported persistence and rollback are preserved.
- Performance impact is recorded.
- Recommendation content is never fabricated.
- Booking and payment flags remain disabled unless explicitly approved.
